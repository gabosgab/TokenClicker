# Token Clicker

`Token Clicker` is a self-contained browser parody clicker focused on one loop: make tokens, buy entities, and let those entities make more tokens.

## Run it

Open [index.html](/Users/gabe/src/TokenClicker/index.html) directly in a browser.

If you prefer serving it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## What is in it

- Manual prompting on click or `Enter`
- Producer entities that generate passive tokens
- Local browser save/load with offline progress
